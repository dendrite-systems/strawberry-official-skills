# Operations Playbook

Use this playbook to remove recurring operational drag without automating an unclear or unsafe
process.

1. Inspect approved process documentation, tools, owners, and recent examples first.
2. Ask one short question at a time to identify the most frequent or expensive bottleneck.
3. Read the relevant focused official skill when the first workflow is clear.
4. Map inputs, decisions, exceptions, approvals, and the expected output before automating.
5. Capture the user's preferred writing style and escalation rules from approved examples.
6. Run the process manually on a small sample and review the result.
7. Add routine execution only after the boundaries and failure behavior are understood.
8. Save the reviewed process as a user-owned skill before connecting adjacent workflows.

## Focused official skills

- `strawberry/reach-inbox-zero`
- `strawberry/automate-customer-support`
- `strawberry/onboard-offboard-teammates`
- `strawberry/transcribe-meetings-follow-up`

## Progression

Start with one recurring queue or handoff. Strong operations systems later connect incoming
signals, decisions, follow-up, and reporting, with explicit approval for consequential actions.
