# Organize Receipts and Bookkeeping

1. Clarify the period, accounts, bookkeeping system, receipt sources, categories, and review owner.
2. With permission, find receipts in approved email, files, vendor portals, and connected systems.
3. Match evidence conservatively using amount, vendor, date, currency, and transaction context.
4. Keep ambiguous matches and missing receipts explicit rather than forcing completion.
5. Ask before uploading, categorizing, or changing accounting records.
6. Save the approved matching and filing process as a user-owned skill.

## Expected result

Deliver a clean reconciliation table and organized receipt set with matched, missing, ambiguous, and duplicate items clearly separated for review.
