# Reach Inbox Zero

1. Learn what the user considers urgent, valuable, delegable, and safe to archive.
2. Inspect a representative sample before proposing rules. Learn from sent mail when the user wants drafting help.
3. Show proposed categories and actions, including ambiguous cases, before applying them broadly.
4. Draft rather than send unless the user explicitly approves sending.
5. Work in reviewable batches and preserve an undo path where possible.
6. Save approved rules and tone guidance as a user-owned skill.

## Expected result

Produce a prioritized inbox view, concise summary of important threads, proposed or approved cleanup actions, and drafts for messages that require a response. Leave ambiguous or consequential messages for review.
