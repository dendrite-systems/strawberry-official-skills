# Automate Customer Support

1. Understand the support channels, volume, common issues, source of truth, tone, service expectations, and escalation rules.
2. Review representative resolved and escalated cases before proposing automation.
3. Separate safe repetitive work from cases requiring judgment, account access, refunds, security review, or empathy.
4. Start with drafts, triage, or a narrow category. Measure quality with the user before expanding.
5. Preserve approved handling rules as a user-owned skill.

## Expected result

Deliver a reviewable support workflow with clear inputs, draft or routing output, escalation boundaries, and a way to assess whether it saved time without reducing support quality.
