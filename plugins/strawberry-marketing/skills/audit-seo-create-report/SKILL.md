# Audit SEO and Create a Report

1. Clarify the site, market, priority pages, competitors, audience, and desired decisions.
2. Gather available analytics and search data with permission, then inspect the live site.
3. Separate observed evidence from hypotheses. Prioritize impact rather than listing every possible issue.
4. Include technical, content, internal-linking, search-intent, and competitive findings only where evidence supports them.
5. For a visual client report, use `visual-artifact` and follow the relevant brand.
6. Save the accepted audit structure as a user-owned skill.

## Expected result

Deliver a concise report with evidence, prioritized opportunities, effort and impact, example fixes, source links, and a practical action plan. For client-facing work, make the report polished and visually clear.
