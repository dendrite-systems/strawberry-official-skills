# Investigate and Fix App Issues

1. Clarify the symptom, expected behavior, impact, environment, and available evidence.
2. Inspect relevant reports, logs, monitoring, recent changes, and code without leaking secrets or user content.
3. Reproduce or establish a minimal evidence chain before proposing a fix.
4. Distinguish confirmed root cause from inference.
5. Implement the smallest maintainable fix when authorized, then validate proportionately.
6. Save a recurring triage process as a user-owned skill when it will be reused.

## Expected result

Deliver a concise diagnosis with evidence, root cause or clearly labeled inference, a reviewable fix when requested, validation results, and any remaining risk.
