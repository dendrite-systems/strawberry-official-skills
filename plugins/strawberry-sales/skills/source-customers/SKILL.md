# Source Customers

1. Clarify the offer, target customer, geography, exclusions, number of prospects, and what makes a lead valuable.
2. Ask for examples of strong existing customers when available. Use them as evidence, not as the only definition of fit.
3. Agree on the fields and qualification rubric before researching at scale.
4. Research prospects from reliable sources, keeping source URLs and separating facts from inference.
5. Deduplicate, rank, and explain why the strongest prospects fit.
6. Review an initial sample with the user before expanding the list.
7. After the output is useful, save the refined sourcing process as a user-owned skill.

## Expected result

Create a clean spreadsheet or table containing the requested number of qualified prospects. Include source links, concise fit reasons, useful contact or company fields when available, and a confidence signal. Never invent missing data.
