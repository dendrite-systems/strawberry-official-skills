# Founder & Executive Playbook

Use this playbook to decide what deserves attention first and how several focused official skills
can work together. Do not attempt to install every workflow at once.

1. Inspect approved company context before asking the user to repeat it.
2. Identify the constraint whose removal would matter most in the next few weeks.
3. Narrow casually with one short question at a time until one useful first workflow is clear.
4. Read the focused official skill for that workflow before proposing its process.
5. Complete one real result, review it with the user, and only then make the process reusable.
6. Preserve durable preferences such as writing style, decision criteria, output format, and tool
   choices so later workflows improve rather than restart.
7. Suggest the next connected workflow only when it naturally follows from completed work.

## Focused official skills

- `strawberry/source-customers`
- `strawberry/prepare-fundraise`
- `strawberry/source-candidates`
- `strawberry/reach-inbox-zero`
- `strawberry/organize-receipts-bookkeeping`
- `strawberry/investigate-fix-app-issues`

## Progression

Begin with urgent leverage: customers, a raise, a key hire, or recurring operational drag. Strong
teams gradually connect research, meetings, follow-up, and shared outputs, but each addition should
solve an observed problem rather than make the system look comprehensive.
