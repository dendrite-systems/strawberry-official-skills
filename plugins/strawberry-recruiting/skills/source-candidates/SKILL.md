# Source Candidates

1. Clarify the role, must-have evidence, useful adjacent backgrounds, location, exclusions, and shortlist size.
2. Ask for a scorecard or examples of strong existing people when available.
3. Agree on the fields and job-related qualification rubric before researching at scale.
4. Use public professional evidence and source links. Do not infer protected or sensitive characteristics.
5. Review an initial sample with the user before expanding the list.
6. Deduplicate and rank candidates with concise, evidence-backed fit reasons.
7. Save the refined sourcing process as a user-owned skill after the user reviews it.

## Expected result

Create a clean spreadsheet or table with the requested number of candidates, source links, relevant experience, fit evidence, open questions, and confidence. Never invent experience or contact details.
