# Extract Web Data

1. Clarify the entities, fields, sources, row count, exclusions, freshness requirements, and intended decision.
2. Agree on a schema and show a small representative sample before scaling.
3. Use reliable sources, preserve source URLs, respect access constraints, and distinguish missing data from negative facts.
4. Normalize formats, deduplicate entities, validate a sample, and flag low-confidence values.
5. Do not invent values to make the table look complete.
6. Save the accepted schema and research procedure as a user-owned skill.

## Expected result

Deliver a clean spreadsheet or dataset with consistent columns, the requested number of rows where evidence permits, source links, normalized values, and explicit missing or uncertain data.
