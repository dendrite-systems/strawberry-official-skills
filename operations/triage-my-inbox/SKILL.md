# Triage My Inbox

## Setup

- How they like their inbox organized. If they already use labels or folders, learn those first.
- What counts as important to them, and what they would happily never see.
- Whether they want a one-off cleanup, a daily pass, or to reach inbox zero.

## A simple daily Routine

One setup that works well: each morning, a Routine goes through new mail, labels everything the way
the user likes, archives what is clearly junk, and tells them which few messages matter most today.

A tip is to keep a small JSON record of the messages already labeled, so later runs don't label the
same messages twice. Keep it simple, and decide the details with the user.

## Worth knowing

- Unread doesn't mean important. Check whether a thread was already handled elsewhere before
  flagging it.
- With thousands of unread emails, labeling every one is slow and expensive. If they still want
  inbox zero, clear the bulk smartly, e.g. search for newsletters, notifications, and senders they
  never open, and archive them in batches. Then look for old unread messages that might still
  matter, and work through what's left together.
- Show a batch before archiving or deleting it the first few times, until the user trusts the rules.
