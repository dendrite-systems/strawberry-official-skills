# Build a Client Progress Report from Your Project Tools

## Setup

- The client, the period, and who reads the report.
- A past report they liked. It shows the format, depth, and tone faster than any description.
- Which tools hold the numbers and the work, e.g. project boards, analytics, ad accounts, or the CRM.

## Worth knowing

- Build one client's report first and let the user correct it before doing the rest.
- Keep every client's accounts, numbers, and output strictly separate.
- Line up date ranges and metric definitions before comparing periods or sources. Flag data that
  doesn't reconcile rather than forcing it.
- Lead with what changed, why it matters, and what happens next, not a wall of metrics.
