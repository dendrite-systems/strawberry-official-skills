# Run a Competitor Analysis

## Setup

- What decision this should help with, e.g. positioning, pricing, a launch, or a sales pitch. The
  purpose decides what to look at.
- Which competitors, including indirect alternatives. If unsure, propose a list and let the user
  edit it before going deep.
- How they want it delivered, e.g. a short brief, a comparison table, or a deck.

## Worth knowing

- Go to the source: pricing pages, changelogs, job posts, ads, reviews, and community threads, with
  links and dates.
- Job posts and hiring patterns often reveal priorities long before an announcement.
- Keep facts separate from inference. Hiring enterprise sellers in a region is a fact; expanding
  into that market is a guess.
- End with what it means for the user, not just how the competitors differ.
